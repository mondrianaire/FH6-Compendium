# FH6 Compendium

A local-first **Forza Horizon 6 tuning & decision database** — a competitive-car and tune reference built around *sourced, confidence-tagged* data rather than the auto-generated tier lists that dominate search.

**Live site:** deployed to GitHub Pages from `dashboard/` (see `.github/workflows/pages.yml`).

## What's in it

- **Cars** — 48 curated meta-car profiles + a class×discipline coverage matrix, with a per-car tune bound from a **1,700+ community tune-code pool** (searchable/filterable by car, tuner, class, discipline).
- **Tuning** — what every slider does, per-discipline templates, upgrade/buy order, and where to find good tunes.
- **Drift**, **Touge**, **Eliminator** — technique + meta guides (the Touge tab is a 4-agent research synthesis with per-pass character, resolved tune settings, and a per-class code list).
- **Rivals** — per-track car+tune recommendations (meta-inferred now, board-verified where a leaderboard was captured).
- **Wheelspin** — FE / wheelspin-exclusive roster with rarity.
- **Progress** — credit / XP / skill-point farming and a day-1 roadmap.

## Design principles

- **Anti-fabrication.** Every claim carries a confidence tag (✅ verified / 🟡 probable / ⚠️ contested). SEO content-farm data is rejected (`data/sources.json` keeps the distrusted list); tune codes are attributed to their creator + source sheet.
- **Facts vs. state.** `data/*.json` holds only game facts; your owned-car tracking lives in your browser's `localStorage`. Visitors start with an empty garage — the owner's captured garage loads only via the **"Load demo garage"** button.
- **No framework, no build step to run.** Vanilla JS + ES modules straight in the browser. `db.js` is a bundle of `data/*.json` generated by `scripts/build-db.mjs`.

## Local dev

```bash
node scripts/build-db.mjs                     # rebuild dashboard/db.js from data/*.json
cd dashboard && python -m http.server 8123    # serve at http://localhost:8123
npm install && npm test                       # headless smoke test (jsdom): clicks every card/tab/overlay
```

## Data & attribution

Tune codes are aggregated from public community tuner sheets (53Rain, GBR Ozzy, LogikJ, aTTaX Johnson, K1Z Gray, OxGRIDRUNR) surfaced via the r/ForzaHorizon6 "good tuners" list, each attributed in-app. FH6 is a live game; the meta shifts with patches — data carries capture dates and is re-ingestible via `scripts/ingest-tuner-sheets.mjs`.
