Built 2026-09-13. Jett flagged the knowledge layer wasn't using the Artifacts infrastructure; these turn settled findings into self-contained, shareable, interactive claude.ai pages (private by default; share from the page menu). Artifacts fit the **knowledge/report layer, NOT the live dashboard** — a sandboxed page can't reach the :8765 daemon or the local api/, so course/turn/live views stay in the dashboard. Each is themed light/dark, no libraries, real data embedded, honesty-gated.

- **Grip Ceiling** — https://claude.ai/code/artifact/edc3253f-a0c7-4708-97f7-bed4e06bf862 — the a_max method + live grip-utilisation calculator on real per-class speed-banded ceilings (course -1050_400, 7,295 samples).
- **Drift Zone Scoring** — https://claude.ai/code/artifact/97c02746-02e3-43bc-879a-25aef09e5f99 — per-distance law (~260k/mi), angle-multiplier curve (real NNLS bins), run estimator, rewind/x2/start-line-glitch, confidence flags.
- **Tuning Diagnostic** — https://claude.ai/code/artifact/5ead06f0-a762-4369-88e2-fcb4d66703cb — symptom→fix ladder→verify test (ref_symptom, 11 symptoms, phase-filtered picker).
- **Setup Baselines** — https://claude.ai/code/artifact/6b576680-8ce1-4b48-851a-a18346fab906 — consensus anchor numbers + spring formula + interactive tire-compound grip/braking frontier + gearbox ladder + lane split + ranked sources.
- **Five-Phase Corner** — https://claude.ai/code/artifact/1ae4e453-d14f-415d-bce6-7fe369ee310f — the turn-analysis design language: SEG_COL (5 phases) ⟂ DGRIP (5 grip states 0–4) + the typical-not-worst rule.
- **The Annotated Course** — https://claude.ai/code/artifact/fa0324f5-477c-45ad-86d5-d09391e0134f — **the NORTH STAR / defined target output** for the grip+turn intelligence (there was none before — the pieces were accreting, not arriving). A portrait money-square where the map is an opportunity heat-map and each turn carries ONE fused verdict: (1) how close to the limit [a_max, shipped], (2) what your fast laps share [Finding Engine, NEXT], (3) the one fix — driving vs tuning [grip-break attribution → diagnostic, NEXT], receipts (5-phase budget/overlay/scatter) one tap down; every line shows basis+n. Build the Finding Engine AS the missing piece of THIS screen, not a standalone card. Design mock (real a_max, illustrative finding/attribution).
- **What Matters Here** (salience/relevance engine) — https://claude.ai/code/artifact/e15b678f-b203-409b-8638-d03744e566c8 — the RULE BEHIND the Annotated Course. Jett's problem: the per-turn view was "way too disjointed… I cannot figure out how we determine WHAT data is most important to show." Answer = **salience = time-cost^wᴛ × confidence^wᴄ × actionability^wᴀ**, one adaptive card that ranks every candidate insight and shows only headline + one support + a drawer, so the unity view stays uncluttered whatever the turn is doing. Interactive: 4 demo turns (T1 dialed / T3 medium / T4 tune-it / T6 thin-data) × live weight knobs — cranking the confidence gate collapses T6's exciting n=2 signal to "Dialed — nothing to spend"; the scoring panel shows every candidate's three factors so you see why the winner won. Honesty is IN the ranking: thin signals get an amber "collect clean laps first" flag not a fix, all-below-floor turns say "nothing to spend", fixes tagged driving vs tuning. accent=amber ◈. This is the mechanism the Annotated Course's per-turn verdict should be driven by.

**Deliberately NOT built (and why):** a **build/tune report** artifact would redraw the v1 build sheet — violates [[jett-port-perfected-surfaces]] (port the perfected surface, never redraw); it's the live dashboard's job. **Class/PI bands** → folds into Setup Baselines. **Data-availability map** → already the Eraser [[fh6-data-availability-diagram]]. **Rivals/Edamame times** → personal data + screenshots, not a general page. **Course-identity workflow** → niche. A **Rivals lab-protocol** (how to run a controlled tune test) is the one remaining medium candidate, overlapping the Diagnostic's verify tests.

**How to apply:** to update one, republish its file path (kept in this session's scratchpad) or pass its URL as `url` from another session; watches cap at 5 (they didn't arm here — static pages, fine). Design pattern: mono-forward data, per-artifact accent (grip=blue, drift=amber, diagnostic=teal, baselines=indigo, corner=graphite+state colors), real embedded data, honest confidence.
