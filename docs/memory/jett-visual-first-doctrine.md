Jett's design doctrine for the dashboard (2026-08-15): "the finished product should have almost no paragraphs at all and uses visual cues, formatted formulas and charts and graphs, not giant paragraphs that are impossible to follow."

**Why:** Large prose swaths are unusable mid-session; the dashboard is a workbench, not an essay. Jett consistently praised the VISUAL deliverables (corner map, car diagrams, timeline strips, real game screenshots) and pushed back whenever information shipped as text.

**How to apply:** Prose budget = max ~1 caption sentence per block. Conversions: mechanism prose → annotated SVG/diagram; rule prose → rule card (icon + imperative headline); "why it works" prose → collapsible drawer (▸ why), hidden by default; numbers-in-prose → stat tiles or formatted formulas (sub/sup, fraction layout, not code strings); procedures → numbered step strips; comparisons → side-by-side extremes; evidence narration → timeline strips. Never delete the underlying knowledge — move it into drawers and tooltips. Related: [[jett-feedback-specificity]] (exact values still required — visual ≠ vague).
